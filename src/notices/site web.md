# Un soutien pour le site ?

Ce site web a été réalisé et rédigé par [Diana](https://github.com/404madiana/EUROBAZAR_web) pendant son stage ouvrier non-rémunéré de juillet. C'est à elle que revient la construction du projet de A à Z, pour obtenir un site web comme celle-ci.

Ceci dit, l'hébergement du site et le nom de domaine sont alimentés pécuniairement dans le compte de Diana.

Pour en savoir plus sur la construction du site, rendez-vous sur [Notice technique.md (GitHub)](https://github.com/404madiana/EUROBAZAR_web/blob/master/Notice%20technique.md).
